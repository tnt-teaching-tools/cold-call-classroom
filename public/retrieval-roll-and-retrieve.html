Roll and retrieve

Use a die to choose between six prepared recall prompts.

How to run it

  1. Prepare six slots

    Assign one taught focus or prompt to each die number.

  2. Roll a number

    Use a physical die to select a slot.

  3. Everyone retrieves

    All group members attempt before discussing answers.

  4. Check and cover gaps

    Verify responses and deliberately revisit unselected slots.

Check learning

Chance does not guarantee coverage. Do not let one confident student answer for everyone.

Credits & source

No sole creator is verified for this generic dice format. Random selection changes the format; learning depends on retrieval and feedback.
