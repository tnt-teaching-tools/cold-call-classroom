Concept map from memory

Retrieve ideas and explain the links between them.

How to run it

  1. Start centrally

    Write one previously taught topic in the middle of a page.

  2. Recall concepts

    Add remembered ideas without consulting a source.

  3. Explain links

    Connect ideas with phrases explaining their relationship.

  4. Check the structure

    Verify facts and links; redraw a small corrected section from memory.

Check learning

A map copied from notes is a different task. Check the linking phrases, not artistic presentation.

Credits & source

No sole creator is claimed for this memory-first classroom variant. Karpicke and Blunt (2011) provide related research on retrieval and concept mapping, not proof that every map format is superior.
