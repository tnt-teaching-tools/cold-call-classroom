Retrieval clock

Organise remembered knowledge into sections of a clock.

How to run it

  1. Label the sections

    Choose four to six taught subtopics and give each a clock section.

  2. Recall independently

    Write relevant knowledge in each section, with notes closed.

  3. Find a connection

    Explain a link between ideas in two different sections.

  4. Check and revisit

    Correct errors; later retrieve a weak section without looking.

Check learning

The clock is an organiser, not a race. Avoid twelve rushed sections that leave no time for correction.
