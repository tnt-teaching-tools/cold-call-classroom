Retrieval placemat

Recall individually before building a shared response.

How to run it

  1. Divide the page

    Allocate a separate writing area to every group member.

  2. Recall alone

    Everyone writes independently without notes or discussion.

  3. Compare ideas

    Take turns explaining recall, and put agreed ideas in the centre.

  4. Check and retry

    Verify the shared response; each learner recalls a corrected idea alone.

Check learning

A group answer can hide individual gaps. Keep each learner’s initial response visible.

Credits & source

Placemat is a widely used cooperative structure. No sole originator is verified here; this guide adds an individual memory-first stage.
