Use on your phone · save to your home screen

Use Cold Call Classroom on your phone or tablet too. Add an icon to your home screen, then tap it whenever you need your classroom.

Android Chrome

  1. Open this website in Chrome on your phone.
  2. Tap the three dots ⋮ beside the address bar.
  3. Choose Add to home screen. Some versions show Install and create shortcut → Create shortcut.
  4. Name it Cold Call Classroom, then tap Add and confirm if asked.

iPhone / iPad Safari

  1. Open this website in Safari.
  2. Tap Share (the square with an upward arrow). Depending on your layout, open the page menu first.
  3. Scroll down and choose Add to Home Screen.
  4. Name it Cold Call Classroom, then tap Add. If Open as Web App appears, you can switch it on.

Your classes on each device: Phone and PC save separately. Use Settings → Export backup / Import backup to transfer classes. A home-screen web app may also save separately from a browser tab, so use the same icon each time and keep a backup.

Opened this link inside Facebook or LinkedIn? Open it in Chrome or Safari first to see the home-screen options. Menu wording varies by device.
